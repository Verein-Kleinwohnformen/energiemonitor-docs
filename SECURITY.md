# Sicherheit melden

Wenn du eine Sicherheitslücke findest, melde sie bitte **nicht** als öffentliches Issue.

- Schreibe an [energiemonitor@kleinwohnformen.ch](mailto:energiemonitor@kleinwohnformen.ch) oder nutze auf GitHub „Report a vulnerability“ im Reiter Security eines Repos.
- Beschreibe das Problem, die betroffene Komponente und wie man es nachvollzieht. Sende keine echten Passwörter oder Schlüssel.

Das Projekt wird von Freiwilligen betreut. Wir bemühen uns, Meldungen ernst zu nehmen und zügig zu prüfen, können aber keine Antwortzeiten zusagen.

Hinweise zum sicheren Betrieb deines Monitors: [Sicherheit](docs/sicherheit.md).
